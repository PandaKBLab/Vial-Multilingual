PandaKB 修改並維護的開放原始碼 Vial 鍵盤設定工具，提供 Windows x64 可攜版。介面支援 12 種語言，首次啟動預設使用英語。

[下載／版本說明](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.0) · [測試報告](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 開始使用

1. 下載 Windows x64 ZIP，完整解壓縮後執行 `Vial.exe`，並保留同一資料夾內的其他檔案。
2. 在 **Settings → Language / 语言** 選擇語言。程式會記住你的選擇。
3. 確認後程式會自動重新啟動。若仍有未儲存的編輯，請先儲存或復原，並結束錄製或韌體更新後再試。

## Windows 首次執行提示

可攜版未簽署，SmartScreen 可能顯示「未知的發行者」。請從本專案的發行頁面下載，並使用同頁的 `SHA256SUMS.txt` 驗證 ZIP。

## v0.1.0

正式版補齊內建選單、QMK 進階設定、鍵碼與滑鼠停駐說明、燈效名稱、裝置資訊及韌體更新提示。標準鍵帽文字、QMK 識別碼、裝置提供的名稱與原始例外資訊保留原值。

每種語言涵蓋 767/767 個內建介面項目。67 項自動化測試通過，並完成 12 種語言的 Windows 成品畫面檢查。實體鍵盤的刷寫和解鎖仍待驗證。
