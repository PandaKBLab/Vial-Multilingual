PandaKB 修改並維護的開放原始碼 Vial 鍵盤設定工具，支援 Windows、macOS 和 Linux。介面支援 12 種語言，首次啟動預設使用英語。

[下載 v0.1.1](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.1) · [測試報告](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 開始使用

1. 依系統選擇下載：Windows x64 可用安裝版或可攜 ZIP（完整解壓縮後執行 `Vial.exe`）；macOS 依晶片選擇 DMG，將程式拖曳到「應用程式」；Linux x86_64 下載 AppImage 後授予執行權限。
2. 在 **Settings → Language / 语言** 選擇語言。程式會記住你的選擇。
3. 確認後程式會自動重新啟動。若仍有未儲存的編輯，請先儲存或復原，並結束錄製或韌體更新後再試。

## Windows / macOS / Linux

Windows 版本未簽署，可能顯示「未知的發行者」；macOS 版本未經 Apple 公證，首次執行可能遭到阻擋（[Apple 說明](https://support.apple.com/en-us/102445)）。下載後可核對 [SHA-256](https://github.com/PandaKBLab/Vial-Multilingual/releases/download/v0.1.1/SHA256SUMS.txt)。Linux 若找不到鍵盤，請參閱 [Vial USB 權限說明](https://get.vial.today/manual/linux-udev.html)。

## v0.1.0

正式版補齊內建選單、QMK 進階設定、鍵碼與滑鼠停駐說明、燈效名稱、裝置資訊及韌體更新提示。標準鍵帽文字、QMK 識別碼、裝置提供的名稱與原始例外資訊保留原值。
