PandaKB에서 수정하고 유지 관리하는 오픈 소스 Vial 키보드 설정 도구입니다. Windows, macOS, Linux에서 사용할 수 있으며 12개 언어를 지원합니다. 기본 언어는 영어입니다.

[v0.1.1 다운로드](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.1) · [테스트 보고서](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 사용 방법

1. Windows x64에서는 설치 프로그램을 실행하거나 포터블 ZIP을 모두 압축 해제한 뒤 `Vial.exe`를 실행하세요. macOS에서는 칩에 맞는 DMG를 선택해 앱을 응용 프로그램 폴더로 옮기세요. Linux x86_64에서는 AppImage에 실행 권한을 부여하세요.
2. **Settings → Language / 语言**에서 언어를 선택합니다. 선택한 언어는 저장됩니다.
3. 확인하면 Vial이 자동으로 다시 시작됩니다. 저장하지 않은 변경 사항을 저장하거나 되돌리고, 기록 또는 펌웨어 업데이트를 마친 뒤 다시 선택하세요.

## Windows / macOS / Linux

Windows 패키지에는 서명이 없어 SmartScreen 경고가 표시될 수 있습니다. macOS 패키지는 Apple의 공증을 받지 않았습니다([Apple 안내](https://support.apple.com/en-us/102445)). 다운로드한 파일은 [SHA-256](https://github.com/PandaKBLab/Vial-Multilingual/releases/download/v0.1.1/SHA256SUMS.txt)으로 확인할 수 있습니다. Linux에서 키보드가 표시되지 않으면 [Vial USB 권한 안내](https://get.vial.today/manual/linux-udev.html)를 참고하세요.

## v0.1.0

정식 버전에서는 기본 메뉴, QMK 고급 설정, 키코드와 도구 설명, 조명 효과 이름, 장치 정보 및 펌웨어 업데이트 메시지 번역을 완료했습니다. 표준 키캡 표기, QMK 식별자, 장치가 제공한 이름과 원본 오류 메시지는 그대로 표시합니다.

각 언어에 등록된 인터페이스 문구 767개가 모두 포함되어 있습니다. 자동 테스트 67개와 패키징된 Windows 앱의 12개 언어 화면 검사를 통과했습니다. 실제 키보드의 펌웨어 기록 및 잠금 해제는 아직 검증하지 않았습니다.
