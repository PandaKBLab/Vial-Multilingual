PandaKB에서 수정하고 유지 관리하는 오픈 소스 Vial 키보드 설정 도구입니다. Windows x64용 포터블 버전을 제공하며, 인터페이스는 12개 언어를 지원합니다. 기본 언어는 영어입니다.

[다운로드 및 릴리스 정보](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.0) · [테스트 보고서](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 사용 방법

1. Windows x64 ZIP 파일을 모두 압축 해제한 뒤, 다른 파일이 함께 있는 폴더에서 `Vial.exe`를 실행합니다.
2. **Settings → Language / 语言**에서 언어를 선택합니다. 선택한 언어는 저장됩니다.
3. 확인하면 Vial이 자동으로 다시 시작됩니다. 저장하지 않은 변경 사항을 저장하거나 되돌리고, 기록 또는 펌웨어 업데이트를 마친 뒤 다시 선택하세요.

## Windows에서 처음 실행할 때

포터블 버전에는 서명이 없어 SmartScreen에서 알 수 없는 게시자라는 메시지를 표시할 수 있습니다. 프로젝트 릴리스 페이지에서 ZIP을 다운로드하고 같은 페이지의 `SHA256SUMS.txt`로 확인하세요.

## v0.1.0

정식 버전에서는 기본 메뉴, QMK 고급 설정, 키코드와 도구 설명, 조명 효과 이름, 장치 정보 및 펌웨어 업데이트 메시지 번역을 완료했습니다. 표준 키캡 표기, QMK 식별자, 장치가 제공한 이름과 원본 오류 메시지는 그대로 표시합니다.

각 언어에 등록된 인터페이스 문구 767개가 모두 포함되어 있습니다. 자동 테스트 67개와 패키징된 Windows 앱의 12개 언어 화면 검사를 통과했습니다. 실제 키보드의 펌웨어 기록 및 잠금 해제는 아직 검증하지 않았습니다.
