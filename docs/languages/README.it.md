PandaKB mantiene questa edizione portatile per Windows x64 di Vial, il configuratore di tastiere open source. L’interfaccia è disponibile in dodici lingue, con l’inglese come lingua predefinita.

[Download e note di versione](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.0) · [Rapporto dei test](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## Come iniziare

1. Estrai tutto il contenuto del file ZIP per Windows x64 e avvia `Vial.exe` nella cartella estratta, mantenendo insieme gli altri file.
2. Scegli la lingua in **Settings → Language / 语言**. La selezione viene memorizzata.
3. Dopo la conferma, Vial si riavvia automaticamente. Salva o annulla le modifiche in sospeso e termina eventuali registrazioni o aggiornamenti del firmware prima di riprovare.

## Primo avvio su Windows

L’edizione portatile non è firmata. SmartScreen potrebbe indicare un autore sconosciuto. Scarica lo ZIP dalla pagina delle versioni del progetto e verificalo usando il file `SHA256SUMS.txt` della stessa pagina.

## v0.1.0

La versione stabile completa le traduzioni di menu, impostazioni QMK avanzate, codici dei tasti e relative descrizioni, effetti luminosi, informazioni sul dispositivo e messaggi di aggiornamento. Le diciture standard dei tasti, gli identificatori QMK, i nomi forniti dal dispositivo e i messaggi diagnostici originali vengono mantenuti.

Ogni lingua comprende tutti i 767 testi dell’interfaccia catalogati. Sono stati superati 67 test automatici e i controlli dell’applicazione Windows in tutte e dodici le lingue. Il caricamento del firmware e lo sblocco su una tastiera fisica devono ancora essere verificati.
