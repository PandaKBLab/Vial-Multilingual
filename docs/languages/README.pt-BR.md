A PandaKB mantém esta edição portátil para Windows x64 do Vial, configurador de teclados de código aberto. A interface oferece 12 idiomas, com inglês como padrão.

[Download e notas da versão](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.0) · [Relatório de testes](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## Como usar

1. Extraia todo o ZIP para Windows x64 e execute `Vial.exe` na pasta extraída. Mantenha os demais arquivos junto ao executável.
2. Selecione o idioma em **Settings → Language / 语言**. A escolha fica salva.
3. Após a confirmação, o Vial reinicia automaticamente. Salve ou descarte as alterações pendentes e conclua gravações ou atualizações de firmware antes de tentar novamente.

## Primeira execução no Windows

A edição portátil não é assinada. O SmartScreen pode indicar um editor desconhecido. Baixe o ZIP na página de versões do projeto e verifique-o com o arquivo `SHA256SUMS.txt` da mesma página.

## v0.1.0

A versão estável completa as traduções dos menus, das configurações avançadas do QMK, dos códigos de tecla e das dicas, dos efeitos de iluminação, das informações do dispositivo e dos avisos de atualização. As inscrições padrão das teclas, os identificadores QMK, os nomes fornecidos pelo dispositivo e os diagnósticos originais são preservados.

Cada idioma cobre 767 dos 767 textos de interface catalogados. Os 67 testes automatizados e as verificações da interface do aplicativo empacotado para Windows nos 12 idiomas passaram. A gravação de firmware e o desbloqueio em teclados físicos ainda precisam ser verificados.
