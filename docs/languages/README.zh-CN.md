PandaKB 修改和维护的开源 Vial 键盘配置器，支持 Windows、macOS 和 Linux。界面支持 12 种语言，首次启动默认使用英语。

[下载 v0.1.1](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.1) · [测试报告](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 开始使用

1. 按系统选择下载：Windows x64 可用安装版或便携 ZIP（完整解压后运行 `Vial.exe`）；macOS 按芯片选择 DMG，将应用拖入「应用程序」；Linux x86_64 下载 AppImage 后赋予执行权限。
2. 在 **Settings → Language / 语言** 选择语言。软件会记住你的选择。
3. 确认后软件会自动重启。请先保存或撤销未保存的编辑，并结束录制或固件更新，再重试。

## Windows / macOS / Linux

Windows 未签名，可能显示“发布者未知”；macOS 未经 Apple 公证，首次运行可能被拦截（[Apple 说明](https://support.apple.com/en-us/102445)）。下载后可核对 [SHA-256](https://github.com/PandaKBLab/Vial-Multilingual/releases/download/v0.1.1/SHA256SUMS.txt)。Linux 若找不到键盘，请参照 [Vial USB 权限说明](https://get.vial.today/manual/linux-udev.html)。

## v0.1.0

正式版补齐内置菜单、QMK 高级设置、键码及悬停说明、灯效名称、设备信息和固件更新提示。标准键帽文字、QMK 标识、设备提供的名称及原始异常信息保留原值。
