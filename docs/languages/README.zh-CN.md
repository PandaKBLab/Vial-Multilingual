PandaKB 修改和维护的开源 Vial 键盘配置器，提供 Windows x64 便携版。界面支持 12 种语言，首次启动默认使用英语。

[下载 / 版本说明](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.0) · [测试报告](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## 开始使用

1. 下载 Windows x64 ZIP，完整解压后运行 `Vial.exe`，并保留同一文件夹内的其他文件。
2. 在 **Settings → Language / 语言** 选择语言。软件会记住你的选择。
3. 确认后软件会自动重启。请先保存或撤销未保存的编辑，并结束录制或固件更新，再重试。

## Windows 首次运行提示

便携版未签名，SmartScreen 可能显示“发布者未知”。请从本项目发布页下载，并用同页的 `SHA256SUMS.txt` 核对 ZIP。

## v0.1.0

正式版补齐内置菜单、QMK 高级设置、键码及悬停说明、灯效名称、设备信息和固件更新提示。标准键帽文字、QMK 标识、设备提供的名称及原始异常信息保留原值。

每种语言覆盖 767/767 条内置界面文字。67 项自动化测试通过，并完成了 12 种语言的 Windows 成品页面检查。实物键盘刷写和解锁仍需验证。
