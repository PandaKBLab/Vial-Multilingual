PandaKB pflegt diese Ausgabe des quelloffenen Vial-Tastaturkonfigurators für Windows, macOS und Linux. Die Oberfläche unterstützt zwölf Sprachen und startet standardmäßig auf Englisch.

[v0.1.1 herunterladen](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.1) · [Testbericht](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## Erste Schritte

1. Für Windows x64 gibt es ein Installationsprogramm und ein portables ZIP. Das ZIP vollständig entpacken und `Vial.exe` öffnen. Unter macOS das DMG für den passenden Chip wählen und die App in „Programme“ ziehen. Unter Linux x86_64 die AppImage-Datei ausführbar machen.
2. Unter **Settings → Language / 语言** die gewünschte Sprache wählen. Die Auswahl wird gespeichert.
3. Nach der Bestätigung startet Vial automatisch neu. Offene Änderungen vorher speichern oder verwerfen und laufende Aufzeichnungen oder Firmware-Updates abschließen.

## Windows / macOS / Linux

Die Windows-Pakete sind nicht signiert; SmartScreen kann warnen. Apple hat die macOS-Pakete nicht notarisiert ([Apple-Hinweise](https://support.apple.com/en-us/102445)). Downloads lassen sich per [SHA-256](https://github.com/PandaKBLab/Vial-Multilingual/releases/download/v0.1.1/SHA256SUMS.txt) prüfen. Wird die Tastatur unter Linux nicht erkannt, hilft die [Vial-Anleitung für USB-Zugriffsrechte](https://get.vial.today/manual/linux-udev.html).

## v0.1.0

Die stabile Version vervollständigt die Übersetzungen für Menüs, erweiterte QMK-Einstellungen, Tastencodes und Tooltips, Beleuchtungseffekte, Geräteinformationen und Firmware-Meldungen. Standard-Tastenbeschriftungen, QMK-Kennungen, vom Gerät gelieferte Namen und technische Fehlermeldungen bleiben im Original.

Alle Sprachen decken 767 von 767 erfassten Oberflächentexten ab. 67 automatisierte Tests und Oberflächenprüfungen der gepackten Windows-Anwendung in allen zwölf Sprachen wurden bestanden. Firmware-Updates und Entsperren an realer Hardware sind noch zu prüfen.
