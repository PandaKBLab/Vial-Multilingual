PandaKB поддерживает эту сборку Vial для Windows, macOS и Linux. Vial — программа с открытым исходным кодом для настройки клавиатур. Интерфейс доступен на 12 языках, по умолчанию выбран английский.

[Скачать v0.1.1](https://github.com/PandaKBLab/Vial-Multilingual/releases/tag/v0.1.1) · [Отчёт о тестировании](https://github.com/PandaKBLab/Vial-Multilingual/blob/main/VALIDATION.md)

## Начало работы

1. В Windows x64 запустите установщик или полностью распакуйте портативный ZIP и откройте `Vial.exe`. В macOS выберите DMG для своего чипа и перенесите программу в папку «Программы». В Linux x86_64 сделайте файл AppImage исполняемым.
2. Выберите язык в меню **Settings → Language / 语言**. Выбор сохранится.
3. После подтверждения Vial перезапустится автоматически. Сохраните или отмените изменения и завершите запись или обновление прошивки, прежде чем повторить попытку.

## Windows / macOS / Linux

Пакеты для Windows не подписаны, поэтому SmartScreen может показать предупреждение. Пакеты для macOS не прошли нотариальное заверение Apple ([справка Apple](https://support.apple.com/en-us/102445)). Проверьте загрузку по [SHA-256](https://github.com/PandaKBLab/Vial-Multilingual/releases/download/v0.1.1/SHA256SUMS.txt). Если Linux не видит клавиатуру, см. [инструкцию Vial по правам доступа к USB](https://get.vial.today/manual/linux-udev.html).

В стабильной версии дополнены переводы встроенных меню, расширенных настроек QMK, кодов клавиш и подсказок, названий эффектов подсветки, сведений об устройстве и сообщений об обновлении.
