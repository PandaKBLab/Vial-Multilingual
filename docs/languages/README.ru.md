PandaKB поддерживает эту портативную сборку Vial для Windows x64. Vial — программа с открытым исходным кодом для настройки клавиатур. Интерфейс доступен на 12 языках, по умолчанию выбран английский.

## Начало работы

1. Полностью распакуйте ZIP для Windows x64 и запустите `Vial.exe` из распакованной папки. Оставьте остальные файлы в той же папке.
2. Выберите язык в меню **Settings → Language / 语言**. Выбор сохранится.
3. После подтверждения Vial перезапустится автоматически. Сохраните или отмените изменения и завершите запись или обновление прошивки, прежде чем повторить попытку.

## Первый запуск в Windows

Портативная сборка не подписана. SmartScreen может сообщить о неизвестном издателе. Скачайте ZIP со страницы релизов проекта и проверьте его по файлу `SHA256SUMS.txt` на той же странице.
